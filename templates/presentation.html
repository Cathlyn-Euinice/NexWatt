SLIDE 03 • TECHNICAL APPROACH & ARCHITECTURE

Full-Stack Architecture & IoT Verification Engine

💻 Frontend Layer

  • Semantic HTML5 & Modern Glassmorphic CSS3 theme.
  • Zero-framework Vanilla ES6+ JavaScript for instant sub-50ms render.
  • Chart.js: Real-time 24-hr micro-grid demand curve & live 5-min IoT timeline.
  • Botanical SVG Engine: Real-time procedural growth stages.

⚙️ Python Backend

  • Python 3 REST API microservice with zero third-party dependencies.
  • Tariff Simulation Engine: TNEB slab & institutional calculations.
  • Power Signature Matching: Heuristics for AC, fans, chargers, and geysers.
  • NAAC Audit Generator: One-click text/PDF audit slip export.

📡 IoT Hardware Node

  • Sensor: PZEM-004T v3.0 (measures Voltage, Current, Active Power W, Energy kWh, PF).
  • MCU: ESP32 DevKit v1 with Wi-Fi HTTP POST every 2s.
  • Ring Buffer: 60-packet offline memory prevents data loss during Wi-Fi disconnects.
  • Cost: Under ₹1,200 for full single-room node.

🔄 System Workflow: From Sensor to Verified Impact

PZEM 230V AC Sensor ──UART──► ESP32 MCU ──Wi-Fi POST──► NexWatt Python Engine ──Signature Check──► Verified Garden XP & Campus Peak Shaving
